# RIS-assisted-HAPS-ISAC
An RIS-assisted HAPS-based ISAC system that employs MIMO beamforming to simultaneously serve users (Us) and sense potential targets (PTs). To overcome severe path loss and blockage in direct HAPS links, a passive RIS is deployed to establish virtual LoS paths, thereby enhancing the downlink SINR for CUs and the sensing beampattern gain toward PTs.
